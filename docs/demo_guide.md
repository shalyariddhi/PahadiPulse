# PahadiPulse — Hackathon Live Demo Walkthrough Guide

Use this step-by-step guide during live judging or demonstration to showcase all 16 steps:

| Step # | Action / View | Expected Result / Highlight |
|---|---|---|
| **1** | Open PahadiPulse Web Admin (`localhost:5173`) or Mobile | Overview map of Uttarakhand showing 20+ tagged destinations across Garhwal & Kumaon. |
| **2** | Inspect **Mussoorie** or **Nainital** | Pressure Badge shows `CRITICAL` (78–82 / 100). |
| **3** | Click **Pressure Breakdown** | Shows 30% Tourism (88/100), 25% Water Stress (82/100), 20% Waste (74/100), 15% Traffic (91/100). |
| **4** | View **7-Day ML Forecast** | Shows upcoming weekend surge reaching 85/100 with confidence bounds. |
| **5** | Switch to **Tourist View / AI Trip Planner** | Open the Smart Itinerary Planner wizard. |
| **6** | Enter Constraints | Days: `4`, Travelers: `3`, Budget: `₹10,000/person`, Interests: `Nature` & `Adventure`. |
| **7** | Click **"Generate Smart Itinerary"** | Optimizer runs in < 200ms. |
| **8** | Examine Recommendation | Replaces congested Mussoorie with **Kanatal, Dhanaulti, and Chopta**. Explains: *"Bypasses high-stress Mussoorie corridor, saving 64% pressure load while fitting ₹10k budget."* |
| **9** | Inspect Day Details | Shows daily activities, estimated costs, and local verified homestay stays. |
| **10** | Explore **Local Providers** | View Pahadi homestays, local trek guides, and organic orchard experiences. |
| **11** | Open **Citizen Issue Reporter** | Simulate a citizen reporting a local bottleneck. |
| **12** | Enter Report Details | Description: *"Severe plastic garbage accumulation and choked drain near Kempty stream"* |
| **13** | Submit Report | AI immediately returns `Category: WASTE`, `Severity: 4/5`, and automated triage explanation. |
| **14** | Switch back to **Admin Dashboard** | New report instantly appears with `AI_CLASSIFIED` badge on the live map. |
| **15** | Advance Triage Workflow | Click `Verify` $\rightarrow$ `Assign` $\rightarrow$ `Resolved`. |
| **16** | View **Regional Analytics** | Inspect district-wise pressure trends, high-stress clusters, and economic distribution metrics. |
